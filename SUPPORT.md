# Support

Cryonis is a community-maintained, pre-release project. Support is best-effort and has no guaranteed response or resolution time.

## Where to ask

- **Bug:** use the GitHub bug-report form with reproducible steps, logs with secrets removed, platform details and the relevant commit or version.
- **Feature or improvement:** use the feature-request form and explain the user problem before proposing an implementation.
- **Setup or usage question:** use GitHub Discussions after it is enabled. Until then, open a clearly labeled question issue.
- **Security vulnerability:** follow [`SECURITY.md`](SECURITY.md) and report it privately. Never disclose it in a public issue.
- **Contribution:** read [`CONTRIBUTING.md`](CONTRIBUTING.md) before opening a pull request.

Please search existing issues and documentation first. Small reproducible examples are much easier for maintainers and contributors to investigate than screenshots without context.

## What maintainers do not provide

Contributors and users must supply and pay for their own Ollama, LiveKit, Deepgram, Cartesia, Apple, Google or other third-party accounts as applicable. Maintainers do not provide shared API keys, production credentials, cloud quota, app-store accounts, private infrastructure or guaranteed free inference.

Never send credentials or private user data when requesting support. Redact tokens, URLs containing credentials, device identifiers, personal paths and conversation content from logs.

## Supported environment

The latest `main` branch is the supported development target until tagged releases begin. CI verifies the versions documented in [`README.md`](README.md); other toolchain or operating-system versions may work but are not guaranteed.
